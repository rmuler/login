<h1> Tela de Login</h1>
<a id="sobre"></a>
<p> A Tela de Login é uma interface simples e minimalista projetada para fins de aprendizado e prática de conceitos de HTML e CSS. Este projeto não possui funcionalidades de autenticação, sendo ideal para compreender a estrutura e estilização de formulários de login.</p>

<a id="deploy"></a>
<p>- Link do deploy: https://rmuler.github.io/login/</p>

<a id="como-configurar"></a>
<h2>Como Usar</h2>
<p>Abra o arquivo index.html no navegador para visualizar a tela de login. O layout inclui campos para nome de usuário e senha, além de um botão de envio. Apesar de não haver funcionalidade prática, a interface pode ser integrada em projetos futuros ou servir como base para estudos adicionais.</p>

<a id="local-files"></a>
<h2>Local Files</h2>
<p>- Pasta "assets": Arquivos de estilo (style.css) e imagens;</p>
<p>- index.html: arquivo com a estrutura da página de login;</p>
